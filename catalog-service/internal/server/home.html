Marketplace API

Каталог товаров, заказы и промокоды.

  • Открыть Swagger UI — авторизация и выполнение запросов прямо в браузере.
  • Проверить доступность сервиса — ответ ok означает, что база данных доступна.
  • Скачать OpenAPI — импортируйте файл в Postman или другой API-клиент.

Первый запрос

Откройте нужную ручку в Swagger UI и нажмите Try it out → Execute.

  1. Зарегистрируйтесь через POST /auth/register. Для покупателя выберите USER, для продавца — SELLER.
  2. Передайте email и пароль в POST /auth/login.
  3. Вставьте полученный access_token в Authorize без префикса Bearer. Swagger UI добавит заголовок к запросам.
GET /products
Authorization: Bearer <access_token>

Access token действует 20 минут. Для обновления передайте refresh_token в POST /auth/refresh.

Если запрос не прошёл

  • 400 — проверьте поля, перечисленные в details.
  • 401 — получите или обновите access token.
  • 403 — операция недоступна вашей роли или заказ принадлежит другому пользователю.
  • 404 — путь или запрошенная запись не найдены.
  • 405 — выберите HTTP-метод из заголовка Allow.
  • 429 — повторите запрос через время из заголовка Retry-After.
